# 飞书 CLI 七类输入源模拟包（Case 05 - 智能家居产品线工业设计）

这批文件基于"2026年度智能家居产品线工业设计"项目场景推导生成，用于模拟飞书 CLI 在该项目下的可用输入源返回。

## 说明

- 这是模拟返回，不是真实接口抓取结果。
- 目录风格对齐 [samples/feishu_cli_case_04_simulated_5d](/D:/Users/HCI_lab/Desktop/github/飞书比赛/samples/feishu_cli_case_04_simulated_5d)。
- 输入源收敛为七类：Base 记录、Base 历史、云文档、聊天历史、会议/妙记、日历、通讯录。
- 只保留正向可用样例，不包含 `*_missing_scope.json`、`*_bot_empty.json` 一类权限或空返回样例。

## 目录

- `01_cloud_docs`
  - 模拟 `docs +fetch --api-version v2` 返回。
  - 包含项目主文档：智能家居产品线工业设计规范与交付，涵盖概念设计、结构设计、手板验证、模具开发四个阶段。
- `02_chats`
  - 模拟群搜索和消息检索返回。
  - 包含项目主群、工业设计组内部群、供应商对接群的消息记录。
- `03_task_risk_register`
  - 模拟 Base 项目表、任务表、风险表返回。
  - 任务覆盖外观冻结、防水等级调整、模具返工、专利规避、产能协调、CMF签样等。
  - 风险覆盖供应链瓶颈、认证变更、知识产权、成本上升等。
- `04_meetings`
  - 模拟会议表和 Minutes 妙记返回。
  - 包含 V1.5迭代同步会、供应商模具评审会、供应链风险应急沟通。
- `05_org_and_team`
  - 模拟项目成员通讯录返回。
  - 包含工业设计组组长、结构工程师、供应商管理经理、品牌经理、CMF设计师。
- `06_calendar`
  - 模拟日历事件和会议参与人返回。
  - 覆盖 4月21日至4月24日的三次关键会议。

## 场景特点

- **设计导向**：涉及外观冻结、CMF评审、曲面设计、防水等级调整等工业设计核心话题。
- **供应链深度绑定**：模具开发、注塑工艺、供应商产能直接制约设计交付。
- **跨部门协同复杂**：需协调结构设计、供应链管理、品牌市场、安全认证四个部门。
- **知识产权敏感**：竞品发布相似外观方案，需评估专利规避空间。
- **成本与设计博弈**：ID曲面导致模具成本上升15%，需在效果与预算间权衡。

## 生成约束

- 保留噪音、旧附件、线下补录不完整、跨项目插话等真实输入问题。
- 不输出评估结论、维度打分、绩效判断等分析性内容。
- Base 风格文件继续使用二维数组 `data` 结构，而不是对象数组。

## CLI 可获取性结论

- 从 CLI 命令能力看，七类输入源都可以纳入自动化取证范围：Base 记录、Base 历史、云文档、聊天历史、会议/妙记、日历、通讯录。
- 覆盖最高：推进闭环力。Base 记录和 Base 历史能支撑任务完整率、延期率、关闭质量，会议/妙记和云文档用于补证。
- 覆盖较高：设计决策力、风险治理力、供应链协调力。关键是把 Base、文档、聊天、会议、日历和通讯录中的时间线与角色关系串起来。
- 覆盖中高：组织行为健康度。聊天历史和会议/妙记是主证据，日历与通讯录用于判断公开场景、必要参会人和非常规时段。
- 已排除来源：邮件、飞书任务中心、审批、OKR、考勤、Drive 评论、外部 PLM/ERP 系统、非飞书供应商管理系统。
