# 飞书 CLI 七类输入源模拟包（Case 06 - 桌面机器人产品研发）

这批文件基于"桌面机器人产品研发项目"场景推导生成，用于模拟飞书 CLI 在该项目下的可用输入源返回。

## 说明

- 这是模拟返回，不是真实接口抓取结果。
- 目录风格对齐 Case 05。
- 输入源收敛为七类：Base 记录、Base 历史、云文档、聊天历史、会议/妙记、日历、通讯录。
- 只保留正向可用样例。

## 目录

- `01_cloud_docs`
  - 模拟 `docs +fetch --api-version v2` 返回。
  - 包含项目主文档：桌面机器人产品研发项目主文档。
- `02_chats`
  - 模拟群搜索和消息检索返回。
  - 包含项目主群消息记录。
- `03_task_risk_register`
  - 模拟 Base 项目表、任务表、风险表返回。
  - 任务覆盖产品概念设计、结构设计、硬件方案、手板制作等。
  - 风险覆盖供应链、供应商质量、技术风险、成本风险等。
- `04_meetings`
  - 模拟会议表和 Minutes 妙记返回。
  - 包含项目启动会、供应商问题专题会、手板问题与外观设计专题会。
- `05_org_and_team`
  - 模拟项目成员通讯录返回。
  - 包含项目经理、结构工程师、硬件工程师、算法工程师、项目经理助理。
- `06_calendar`
  - 模拟日历事件和会议参与人返回。
  - 覆盖项目启动会、供应商问题专题会、手板问题与外观设计专题会。

## 统一主键

- `project_id`: `PJT-CASE-06`
- `manager_id`: `MGR-CASE-06`
- `manager_name`: `周牧`
- `manager_title`: `项目经理/工业设计负责人`
- `meeting_id`: `MTG-CASE-06-01` 至 `MTG-CASE-06-03`

## 场景特点

- **硬件研发导向**：涉及结构设计、硬件方案、手板制作、功能测试等硬件产品研发核心话题。
- **供应链风险突出**：核心芯片缺货、手板供应商质量问题是主要风险点。
- **进度压力大**：项目周期紧张，手板延期对整体进度影响大。
- **技术挑战**：续航优化、算法识别率等技术创新点。
- **组织健康问题**：管理者存在深夜消息、高压语言等组织行为问题。

## 生成约束

- 保留任务延期、手板返工等真实问题。
- 不输出评估结论、维度打分、绩效判断等分析性内容。
- Base 风格文件继续使用二维数组 `data` 结构。

## CLI 可获取性结论

- 从 CLI 命令能力看，七类输入源都可以纳入自动化取证范围。
- 覆盖最高：推进闭环力、风险治理力。
- 覆盖较高：协同调度力、方向校准力。
- 覆盖中等：组织行为健康度。
